# Pizza Sales Analysis

📌 Project Overview

This project transforms one year of pizza sales data into an interactive, insight-driven dashboard.

In this project I have 
- Built a Power BI dashboard for real-time business decision-making.
- Examined total sales and revenue trends across the full year.
- Evaluated which pizzas drive the most revenue and orders.
- Uncovered ordering patterns by day, time, and pizza type.

🛠 Tools & Technologies

Excel - Data Cleaning and accuracy.
Power BI – Data modeling, DAX measures, and dashboard visualization.
SQL – Data aggregation and key findings.

📈 Dashboard Features

- KPI Cards
- Interactive Slicers
- Synced Filters
- Dynamic Tooltip
- Multi-Page Navigation
- DAX Measures

📊 Key Performance Indicators (KPIs)

- Total Revenue
- Average Order Value (AOV)
- Total Pizzas Sold
- Total Orders

📈 Dataset & Preparation

The analysis brings together 4 structured CSV files, cleaned in Excel and integrated in SQL Server to create a unified model for analysis.
- Loaded, cleaned and transformed raw Excel data.
- Joined tables & Created a View in SQL.
- Imported the SQL View into Power BI.

📋 Dashboard Pages

🔹Overview - Overall business performance and key KPIs.
🔹Sales Analysis - Revenue and order trends across categories and time.
🔹Pizza Analysis - Best and worst performing pizzas by revenue and quantity.
🔹Time Analysis - Sales patterns by hour, weekday, and month.

💡 Key Insights

- 📈 Revenue peaked in July at $72.5K.
- 📈 Large sized pizzas generate 46% of revenue.
- 📈 The Thai Chicken Pizza is the top revenue generator.
- 🕒 Lunch (12–1 PM) and Dinner (5–7 PM) are the busiest hours.
- 📈 Friday is the busiest day with the highest orders.
- 📉 October generated the lowest monthly revenue.
- 📉 October generated the lowest monthly orders.
